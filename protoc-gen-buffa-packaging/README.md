# reallyme-protoc-gen-buffa-packaging

This is the **0.1.0** fork maintained by **ReallyMe Technologies Limited**, distributed under Apache-2.0. The upstream license and attribution notices are retained. See [fork provenance and migration](https://github.com/reallyme/buffa/blob/reallyme-v0.1.0/FORK.md) for the package aliases, matching generator release, cleanup features and limits.

Companion protoc plugin that emits the Rust module tree for files generated by `reallyme-protoc-gen-buffa`. Install both packages at the same release version.

```sh
cargo install reallyme-protoc-gen-buffa-packaging --version '=0.1.0' --locked
protoc-gen-reallyme-buffa-packaging --version
```

The expected version output is `protoc-gen-reallyme-buffa-packaging 0.1.0`. Use `local: protoc-gen-reallyme-buffa-packaging` in Buf, or `--reallyme-buffa-packaging_out` with protoc.

See the [two-plugin configuration](https://github.com/reallyme/buffa/blob/reallyme-v0.1.0/FORK.md). This package emits module wiring; it requires the matching message generator's output.
