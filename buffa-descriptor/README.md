Protobuf descriptor types for [buffa](https://crates.io/crates/reallyme-buffa).

This crate provides self-hosted Rust types for `google/protobuf/descriptor.proto`
and `google/protobuf/compiler/plugin.proto`, generated by buffa-codegen itself.
It underpins both compile-time code generation and runtime reflection.

The only runtime dependency is `buffa` — no external protobuf library required.

## Runtime reflection

`DescriptorPool`, `DynamicMessage`, and the reflection traits are available
with the optional `reflect` feature. It is not enabled by default, so add the
crate with the feature:

```sh
cargo add reallyme-buffa-descriptor@=0.1.0 --rename buffa-descriptor --features reflect
```

The JSON API of `DynamicMessage`, for example `to_json`, the `from_json`
constructors and `DynamicMessageSeed`, needs the `reflect` and `json` features
together: `cargo add reallyme-buffa-descriptor@=0.1.0 --rename buffa-descriptor --features reflect,json`.

The descriptor and protoc plugin message types need no feature. Enable
`reflect` only to use `DescriptorPool`, `DynamicMessage` or the reflection
traits.
